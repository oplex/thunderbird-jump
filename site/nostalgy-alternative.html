Why the “Experiment APIs” row matters

Experiment APIs let an add-on reach directly into Thunderbird's own code. That allows features the official API doesn't offer, but Thunderbird changes that code often, so these add-ons cap the Thunderbird versions they accept and need a new release after many Thunderbird updates. The add-ons' own listings describe this:

Nostalgy++

Its listing points users of Thunderbird 153/155 to a GitHub download while the version on addons.thunderbird.net catches up.

QuickFolders

Its listing has a “Thunderbird 143 problems” note about a new version awaiting review and a false incompatibility warning after an update.

ThunderJump

Uses only official MailExtension APIs, declares no upper version limit, and runs its test suite inside real Thunderbird builds, from 91 up to the newest release, on every change.

This is a trade-off, not a verdict: Experiment APIs are how Nostalgy++ offers rules and QuickFolders its tab bar, which official APIs can't do today.

Which one should you use?

ThunderJump

You want a fast keyboard jumper with shortcuts, folder creation, undoable moves and a search page, that keeps working after Thunderbird updates.

Nostalgy++

You rely on rules and learned folder suggestions, or Nostalgy's classic key set.

Quick Folder Move

You mainly need move, copy and tag from one small popup.

QuickFolders

You prefer a visible bar of favorite folders as tabs, with categories.

They can be installed side by side, so trying ThunderJump costs nothing: install it, press Ctrl+Shift+Space, and type.
