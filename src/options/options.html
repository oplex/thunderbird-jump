ThunderJump

ThunderJump is installed

Press Ctrl+Shift+Space in the mail window (Mac: ⌘⇧Space), type a few letters of a folder name and press Enter. Type ? in it for all commands.

Reinstalling? Restore your shortcuts and settings from a backup file (thunderjump-backup.json, usually in your Downloads folder):

Shortcuts

Set from the palette with :jj1 or :jj name; jump with j1 or :j name.

NameFolder

Behaviour

Moving messages

Off by default: ThunderJump then never touches your mail. When on, select messages and press Alt+Shift+M (or right-click → Move with ThunderJump…). Every move can be undone (Alt+Shift+Z, Ctrl+Z in the palette, or below).

WhenMessagesFrom → to

Backup

Thunderbird deletes an add-on's settings when you remove it and doesn't warn the add-on first, so keep a backup file if you want to get them back.

Keyboard shortcuts

Click a box and press the new keys (for example Ctrl+Alt+J). Backspace clears it, Esc cancels. Give j1–j5 a key to jump without opening the palette.
